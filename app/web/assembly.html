Assembly planner

Drawing evidence → reviewed components → placements and mates → checked assembly

Drawing reader · View source sheets

1. Read the BOM across all sheets

Repeated table rows are merged by scope and item number. Review unreadable quantities and conflicting identifiers against the original sheets.

2. Supply the component geometry

Use exact supplier models for purchased parts. Build fabricated parts using the existing custom feature workflow, review their dimensions, and attach the resulting SLDPRT. Nested assemblies and STEP conversion need a separate import step.

3. Review the assembly plan

Confirm each BOM row and model after comparison with the drawing, then set bom_complete and unit_confirmed. Enter each occurrence's placement and dimensional evidence, analytic face selectors for mates, and expected overall size with its evidence. All lengths use the plan's unit; mate angles use degrees.

Clear an issue only after resolving it against source evidence. Missing geometry and unknown dimensions block approval. File uploads screen the container format; geometry and configurations are checked in SolidWorks during execution.

Download saved assembly plan

The downloaded plan can be incomplete while you gather details. Approval and execution are separate CLI steps. This page never starts SolidWorks.

These numbers illustrate the schema. Surface points are in each part's local coordinates. Plane selectors need point and direction; cylinders also need radius. Multiple matching faces stop execution. Assembly rotations use SolidWorks MathTransform row-major values.
